Customer Segmentation Using Machine Learning

Introduction

This project groups customers based on annual income and spending score using Machine Learning.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

Algorithm

K-Means Clustering (Unsupervised Learning).

Features

- Customer segmentation
- Elbow Method graph
- Customer cluster visualization
- Spending score bar chart
- New customer prediction
- CSV export

How to Run

Install libraries:

pip install pandas numpy matplotlib seaborn scikit-learn

Run:

python customer_segmentation.py

Conclusion

This project helps businesses understand customer groups and their spending patterns.
